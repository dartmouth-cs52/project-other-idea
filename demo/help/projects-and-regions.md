# Projects and regions

A project is one app or service that you run on Acme. Each project has its own deploys and its own web address. The Projects page lists every project in the workspace. Open it with Projects in the bar at the top, or with View projects on the Overview page.

To create a project:

1. On the Projects page, press New project, above the list.
2. In the New project dialog, type a name in Project name. A name is required.
3. Choose a Region: US East or EU West.
4. Press Create project. Press Cancel to close the dialog without creating anything.

The new project is added to the end of the list. It is empty until its first deploy.

Any teammate can create a project. The name becomes part of the project's web address, so it cannot be changed afterwards. We suggest lowercase letters and hyphens, as in storefront-api.

The region is where the project runs and where its data is kept. US East is in Virginia and EU West is in Ireland. Pick the one nearest to the people who use your app. US East is selected unless you choose EU West.

A region cannot be changed after a project is created. To run in the other region, create a second project there and deploy to it. The first project keeps running as before.

How many projects a workspace can have depends on its plan. The numbers are in the article Usage and limits.
